## 📖 Sobre

Este repositório reúne os exercícios que resolvo enquanto aprendo Python, desde o básico até desafios mais elaborados. Serve como registro da minha evolução.

## 📂 Estrutura

```
Cody-Python/
├── exercicios de python/   # Exercícios e desafios resolvidos
└── .idea/                  # Configurações do PyCharm
```

## ▶️ Como executar

```bash
# Clone o repositório
git clone https://github.com/Cariocadev-del/Cody-Python.git

# Entre na pasta
cd Cody-Python/"exercicios de python"

# Execute um exercício
python nome_do_arquivo.py
```

> Requer Python 3.8 ou superior.
